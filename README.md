# 📊 Student Performance Dashboard

## 📌 Project Overview
This Power BI dashboard analyzes student performance using interactive visualizations and key academic metrics. It helps identify trends, compare student results, and gain meaningful insights for data-driven decision-making.

## 🎯 Objectives
- Analyze student academic performance
- Track overall trends and key metrics
- Compare performance across different categories
- Create an interactive and easy-to-use dashboard

## 📈 Dashboard Features
- KPI Cards
- Bar Chart
- Line Chart
- Pie & Donut Charts
- Gauge Visual
- Interactive Slicers

## 🛠️ Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## 📂 Repository Contents

| File Name | Description |

| **STUDENT PERFORMANCE DASHBOARD.pbix** | Power BI dashboard file |

| **README.md** | Project documentation |

## 🚀 How to Use
1. Download the repository.
2. Open **STUDENT PERFORMANCE DASHBOARD.pbix** in Power BI Desktop.
3. If prompted, connect the file to **student performancedata set.xlsx**.
4. Explore the dashboard using the slicers and filters.

## 📊 Key Insights
- Overall student performance overview
- Subject-wise performance comparison
- Interactive filtering and trend analysis
- Clear visualization of academic metrics
